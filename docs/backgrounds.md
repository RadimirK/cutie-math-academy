# Фоны сцен

> Фоны рисуются так же, как персонажи (`docs/character-art.md`): описание в YAML, картинку
> делает детерминированная программа в том же пиксельном стиле. Свет, объём, падающие тени,
> обводка и цветовые рампы у фонов и героинь общие, поэтому сцена читается как одна картинка.

## Как устроено

| Уровень | Где лежит | Что задаёт |
|---|---|---|
| Стиль | `SCENE`, `SCENERY_COLORS`, `sceneryPalette` в `src/art/style.ts` | Размер холста, цвета материалов по умолчанию, рампы |
| Предметы | `content/art/props/<id>.yaml` | Окно, доска, шкаф, стол… в виде фигур с параметрами |
| Фон | `content/backgrounds/<id>.yaml` | Палитра и список предметов с местом и параметрами |

Сцена ссылается на фон по id: `background: classroom`. Если в `content/assets/backgrounds/`
лежит картинка с этим именем (`classroom.png`), показывается она, иначе рисуется фон из YAML.
Загрузчик контента требует, чтобы для каждой сцены был YAML фона.

**Холст 640×360.** На сцене героиня (256 пикселей) занимает 72% высоты экрана, а фон всю
высоту, поэтому при 360 пикселях пиксель фона почти равен пикселю героини. Фон растягивается
`background-size: cover` без сглаживания. Середину и низ закрывают героиня и окно диалога:
главное стоит держать в верхних двух третях и по бокам.

## Фон

```yaml
id: classroom
name: Аудитория
palette: { wall: '#efe4cf', floor: '#b77d50' }   # остальные материалы из SCENERY_COLORS
props:                                            # сзади вперёд
  - { prop: room, at: [0, 0], floor: 272, panel: 56 }
  - { prop: window, at: [26, 66], w: 90, h: 128, curtains: side }
  - { prop: blackboard, at: [320, 70], w: 330, writing: logic }
  - { prop: plant, at: [604, 272], size: 1.15 }
```

`at` — пиксель холста, куда попадает (0, 0) предмета, `scale` — пикселей на единицу предмета
(по умолчанию 1). Остальные поля — параметры предмета.

**Варианты.** `base: classroom` берёт палитру и предметы другого фона, а свои кладёт сверху:
вечерняя аудитория — это аудитория с закатной палитрой и длинным косым солнечным пятном.
`set` меняет параметры унаследованных предметов по их id: лекционная для алгебры — это
лекционная с `set: { blackboard: { writing: matrices } }`. Когда меняется больше (звёзды в
окне и другое освещение), список предметов пишется целиком, как у `library_night`.

| `courtyard_after_rain` | тот же двор после ливня, большая лужа | симпатия |
| `dressing_room` | гримёрка театрального кружка: вешалка с костюмами, ширма, зеркало с лампочками, коробки | симпатия |
| `council_room` | комната студсовета вечером: гирлянда, плакаты, стол с листовками, ночное окно | симпатия |
| `dorm_room`, `dorm_room_night` | комната в общежитии: кровать, полки, стол с лампой, окно со шторами | — |
| `storeroom` | тесная кладовка: стеллажи с коробками, ведро со шваброй, лампочка на проводе | — |

Доска показывает предмет: таблица истинности у дискретки, график предела у анализа, матрицы
у линала. Сцене урока стоит брать фон своего предмета, сцене симпатии — место, о котором
говорит её текст.

**Материалы:** `wall, trim, floor, ceiling, wood, dark_wood, board, chalk, glass, sky, cloud,
metal, paper, fabric, plant, blossom, lilac, pot, cork, haze, lamp, book1…book5, accent, shine`.
`haze` — далёкое в дымке (город на горизонте), `blossom` — цветы сакуры, `lilac` — сирень,
`cork` — пробка и картон. Палитра фона
перекрашивает любой из них: в библиотеке стены темнее, а `accent` зелёный, поэтому лампа и
кайма ковра там зелёные.

## Предмет

Предмет написан теми же фигурами, что детали персонажей: `poly`, `ellipse`, `strand`,
`stroke`, `stamp` с теми же полями (`when`, `mirror`, `clip`, `seam`, `shadow`, `tone`, `erase`).
Отличия:

- координаты — пиксели холста относительно (0, 0) предмета; где эта точка (угол, центр,
  середина на полу), написано комментарием в начале `shapes`;
- `mirror` отражает относительно вертикали через (0, 0) предмета, а не центра холста;
- `shade` по умолчанию `flat`: большие поверхности не нужно скруглять;
- у фигур нет `slot`, глубина — порядок предметов в фоне и фигур в предмете.

**Повторы.** `repeat: { count, step }` рисует копии фигуры, каждую на `step` дальше
предыдущей. В выражениях фигуры номер копии виден как `$i`, а `%` — остаток от деления.
`cycle` по очереди меняет материал копий, на штампы он не действует (у них материал в `key`).
Так сделаны книги на полке, доски пола и точки последовательности на доске:

```yaml
- poly: [['4 + 7 * $i', '$top + (($i * 7) % 5) * 2'], …]   # высота книг «случайная», но детерминированная
  repeat: { count: '($w - 12) / 7', step: [0, 0] }
  cycle: [book1, book2, book3, book4, book5]
  seam: true                                                 # каждая книга обведена отдельно
```

**Надписи мелом** — штампы из пиксельного шрифта 3×5. Обычные формулы в сценах пишутся на
доске героини (`figure`), а надписи на фоне — это декорация.

## Проверки и просмотр

`npm run content:validate` проверяет схему предметов и фонов, ссылки сцен на фоны и рисует
каждый фон. `npm run art:render -- <папка> [id ...]` сохраняет `<id>.bg.png` и `<id>.bg.x2.png`.
Фон рисуется 0,3–0,6 с и кэшируется на время сессии.
